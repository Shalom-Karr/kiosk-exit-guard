What's in v0.2.0

UAC manifest

Embedded into the exe — every launch requests admin elevation cleanly.

First-run modal

No flags needed. Drop the exe, double-click, set the password in the prompts.

Self-install at startup

Registers a Task Scheduler entry that re-launches the exe at every user logon with HIGHEST run level.

Filter mode hotkey

Ctrl+Shift+Alt+K → password → filter mode flips on/off. State persists across reboots.

Keystroke blocks

Win+R, Win+E, Win+D, Ctrl+Shift+Esc silently swallowed when filter mode is on.

Registry policy lockdown

Sets DisableTaskMgr and NoRun under HKCU. Restored automatically when filter mode is off.

How filter mode works

Filter modeWhat happens
OFF (default)All keys pass through. Registry policies are clean. The hook is installed but only listens for the toggle hotkey.
ONAlt+F4 prompts for the password. Win+R/E/D and Ctrl+Shift+Esc are dropped. Task Manager refuses to launch ("disabled by your administrator"). Run dialog refuses to open.

The toggle hotkey is Ctrl+Shift+Alt+K. Pressing it any time — in either mode — opens a password prompt. Correct password flips the mode and persists the state to filter_mode.state next to the exe.

Setup

  1. Download the exe (button above) and drop it in C:\Program Files\KioskExitGuard\.
  2. Double-click it. Approve the UAC prompt.
  3. Set a password in the two prompts that appear.
  4. The exe auto-installs a Task Scheduler entry. From now on it relaunches at every user logon.
  5. Press Ctrl+Shift+Alt+K to turn filter mode on whenever you want the kiosk locked down.
SmartScreen warning on first launch. The exe is unsigned. Click More info → Run anyway. If Defender quarantines it, add the install directory to the exclusion list.

What it doesn't block

  • Ctrl+Alt+Del and Win+L go through Windows' Secure Attention Sequence, which sits below any user-mode hook. No user-mode tool can intercept them. A determined user can always reach the SAS menu or lock screen.
  • Booting from USB / safe mode — set a BIOS password to prevent this.
  • An admin with an elevated terminal can still kill the exe. The Task Manager disable makes this a much higher bar for a standard kiosk user.

CLI flags

kiosk-exit-guard.exe                  # normal run — restores filter-mode state and installs hook
kiosk-exit-guard.exe --set-password   # change the password
kiosk-exit-guard.exe --reset          # restore registry, reset filter-mode to OFF (recovery)
