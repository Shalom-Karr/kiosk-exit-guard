kiosk-exit-guard

A tiny Windows utility that password-gates Alt+F4 for kiosk setups where Assigned Access isn't available.

What it does

Installs a low-level keyboard hook. When you press Alt+F4, instead of closing the focused window, you get a password prompt. Right password closes the window; wrong password (or cancel) shows a brief "Wrong password" toast and the keystroke is dropped.

KeypressBehavior
Alt+F4 + correct passwordForwards WM_CLOSE to the previously-focused window
Alt+F4 + wrong password or cancelKeystroke swallowed; auto-dismissing "Wrong password" toast (2s)
Anything elseUntouched — normal behavior

Quick setup

  1. Download the exe (button above) and place it in C:\Program Files\KioskExitGuard\ (admin write, user read).
  2. Run once as admin to set the password: 
    "C:\Program Files\KioskExitGuard\kiosk-exit-guard.exe" --set-password
    This writes a bcrypt hash to password.hash next to the exe.
  3. Auto-launch on the kiosk user's login via Task Scheduler: 
    $action = New-ScheduledTaskAction -Execute "C:\Program Files\KioskExitGuard\kiosk-exit-guard.exe"
$trigger = New-ScheduledTaskTrigger -AtLogOn -User "luach"
Register-ScheduledTask -TaskName "KioskExitGuard" -Action $action -Trigger $trigger -RunLevel Limited
First run will hit Microsoft Defender SmartScreen because the binary is unsigned. Click More info → Run anyway. Add the install directory to Defender exclusions if needed.

What it doesn't do

This is a single-key guard. It does not block Win+R, Win+E, Ctrl+Shift+Esc, or other escape paths — lock those down via Group Policy or registry. And because the guard runs in user space, anyone who reaches Task Manager can kill it; pair with a standard (non-admin) kiosk account and a disabled Task Manager policy.

How it works

  • SetWindowsHookExW(WH_KEYBOARD_LL) — global low-level keyboard hook
  • Detects Alt+F4 via GetAsyncKeyState + virtual-key code 0x73
  • Password prompt is a native Win32 input box (masked) via ncruces/zenity
  • On correct password, posts WM_CLOSE to the previously-focused window (cleaner than re-injecting Alt+F4)
  • Password stored as a bcrypt hash at cost 10 in password.hash
  • Built with -ldflags="-H windowsgui -s -w" so it runs invisibly without a console window
