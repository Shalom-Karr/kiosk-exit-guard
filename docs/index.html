What it does

UAC elevation

Embedded manifest. Every launch requests admin consent cleanly. The Task Scheduler entry uses HIGHEST run level, so logon launches are silent.

First-run setup

No flags needed. Drop the exe, double-click, set a password, pick the kiosk URL. The exe self-installs the startup task.

HKLM password storage

Bcrypt hash lives in HKLM\Software\KioskExitGuard\PasswordHash. Admin-write only — a standard kiosk user can't delete it.

Filter mode hotkey

Ctrl+Shift+Alt+K → password → flips ON/OFF. State persists across reboots.

Pause duration prompt

Toggling OFF asks for a pause length. 5m / 15m / 30m / 1h / Indefinite. Auto re-enables when the timer fires.

Chrome kiosk watchdog

30-second tick. If Chrome isn't running, launches chrome.exe --kiosk <url>. If Chrome is running but not the kiosk URL, kills and relaunches.

Keystroke blocks

Filter mode ON: Alt+F4 password-gated. Every other Ctrl/Win/Alt combo (Ctrl+F4, Alt+Tab, Win+R/E/D, Ctrl+Shift+Esc, …) silently swallowed.

Registry policy lockdown

Filter mode ON: sets DisableTaskMgr=1 and NoRun=1 under HKCU. Cleared automatically when you flip OFF.

Setup

  1. Download the exe (button above) and place it in C:\Program Files\KioskExitGuard\.
  2. Double-click. Approve the UAC prompt.
  3. Set a password in the two prompts.
  4. Set the kiosk URL. Pre-filled with https://skluach.pages.dev/CMH/ — change it to your URL or accept the default.
  5. The exe self-installs a Task Scheduler entry named KioskExitGuard that re-launches at every user logon with HIGHEST run level.
  6. Press Ctrl+Shift+Alt+K any time to flip filter mode on or off.
SmartScreen warning on first launch. The exe is unsigned. Click More info → Run anyway. If Defender quarantines it, add the install directory to the exclusion list. (Unsigned exes with low-level keyboard hooks share a profile with keyloggers — the heuristic is doing its job.)

CLI flags

kiosk-exit-guard.exe                  # normal run — restores state, installs hook, starts watchdog
kiosk-exit-guard.exe --set-password   # change the password (UAC-elevated)
kiosk-exit-guard.exe --set-url        # change the kiosk URL (UAC-elevated)
kiosk-exit-guard.exe --reset          # password-gated — clears registry policies + resets filter mode

--reset requires the password. If you've lost the password entirely, an admin can wipe the registry key HKLM\Software\KioskExitGuard via regedit to fully reset the install.

What it doesn't block

  • Ctrl+Alt+Del and Win+L are handled by Windows' Secure Attention Sequence, which sits below any user-mode hook. No user-mode tool can intercept them.
  • Booting from USB / safe mode bypasses everything. Set a BIOS password.
  • An admin with an elevated terminal can still kill the exe. The Task Manager disable raises the bar for a standard kiosk user but doesn't stop another admin.
